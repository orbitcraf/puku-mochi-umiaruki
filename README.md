# ぷくともちの うみあそび

元気な紫色の「ぷく」と、のんびり屋で白〜水色の「もち」が海で一日を過ごす、全11ページのデジタル絵本です。

PCでは見開き、スマートフォンでは縦長の1ページとして表示されます。ボタン、左右キー、スワイプでページをめくれます。

## 物語

1. 表紙
2. 海へ行く
3. 浜辺に着く
4. 海で遊ぶ
5. 貝殻を探す
6. 砂のお城を作る
7. シュノーケリング
8. 海の生き物と出会う
9. 休憩してお弁当を食べる
10. 夕日を見る
11. 夜の海で一日を終える

## 操作

- 「前へ」「次へ」ボタン
- キーボードの左右キー、Home、End
- スマートフォンの左右スワイプ
- 右上の「おと」で海の環境音をON/OFF（初期状態はOFF）
- 各場面右下の丸いボタンで、小さな音とアニメーションを再生
- 最終ページの「おもいでを みる」でアルバムを表示
- `#page-shells` のようなURLで指定ページを直接表示

## ローカルで確認

静的ファイルとして配信します。Pythonが使える場合の例です。

```powershell
python -m http.server 4173
```

ブラウザで `http://127.0.0.1:4173/` を開いてください。

静的参照の検査：

```powershell
node scripts/check-static.mjs
```

## GitHub Pages

このリポジトリは `orbitcraf/puku-mochi-umiaruki` 用です。`.github/workflows/deploy-pages.yml` によりGitHub Pagesへ配置できます。

## 画像について

- 海版の画像は `assets/sea-*.png` に保存しています。
- ぷくは紫、もちは白〜水色に統一しています。
- 参考画像は場面構成、色彩、絵本らしい空気感の参考として使用し、文字やUIを焼き込まないオリジナル画像を生成しています。
- 山版の既存画像は比較・保全のため削除や上書きをしていません。

## アクセシビリティと表示

- 操作ボタンに日本語のラベルを設定
- 現在ページをライブ領域で通知
- キーボード操作とフォーカス表示に対応
- `prefers-reduced-motion` に対応
- 320px以上のスマートフォン幅と横長PC表示に対応
